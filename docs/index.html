Why "pinned" matters

Most backtests you find online cannot be rerun: the data provider revises prices, the seed is missing, the package versions drift. Every series used here lives in data/raw/ as a CSV, with its row count, date range and sha256 in data/manifest.json. If a number on this site ever disagrees with the pinned data, the test suite fails, not your trust. Earlier exploratory studies in this repo (Monte Carlo portfolio risk, a moving-average baseline) had their metrics withdrawn when an audit found method bugs - the corrected versions taught the rules these three studies now follow: archive inputs, state costs, no lookahead, no silent selection.
